# FileConvert — Telegram Mini App

Профессиональный Mini App для Telegram с конвертацией изображений и файлов.

## Текущий MVP

- Telegram WebApp SDK
- Light/Dark theme
- JPG / PNG / WEBP
- конвертация изображений прямо на устройстве
- качество JPG/WEBP
- локальная история
- адаптивный мобильный интерфейс
- GitHub Pages deployment

## Следующий этап

- Telegram Bot + Mini App launch button
- Cloudflare Worker API
- R2 для временных файлов
- очередь задач
- серверный converter для PDF/DOCX/XLSX/PPTX/FFmpeg
